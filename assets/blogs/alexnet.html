01 / THE PROJECT

Not just an implementation. A reproduction.

The goal was to reproduce AlexNet as described in the original paper: its architecture, layers and training setup, then run the complete pipeline locally—from dataset loading and augmentation through training, evaluation and visualization.

The interesting part was the scale.

The training set was roughly 1.2 million images across 1,000 classes. The dataset occupied about 150 GB, while the model contained 62,378,350 trainable parameters.

02 / THE ARCHITECTURE

See the network shrink, deepen, and classify.

AlexNet is an eight-layer learned network: five convolutional layers followed by three fully connected layers. The visualization below makes the changing spatial resolution, channel depth and major operations visible at a glance.

256 × 256 source image → random 224 × 224 training crop
5 convolutional + 3 fully connected layers
FEATURE EXTRACTOR CLASSIFIER

Original-paper architecture: five convolutional layers + three fully connected layers, followed by a 1000-way softmax. The paper specifies a 224×224×3 network input, while the stored training images are 256×256 and are cropped to 224×224 patches during training.

Parameter note: the original paper describes the model as having about 60 million parameters; the project README reports 62,378,350 trainable parameters for the implementation. These are shown separately as paper and implementation facts.

01 / SPATIAL SHRINKING
224×224 → 55×55 → 27×27 → 13×13 → 6×6

Pooling progressively compresses spatial information while the convolutional stack builds increasingly rich feature representations.

02 / FEATURE DEPTH
96 → 256 → 384 → 384 → 256

The network trades spatial resolution for many feature maps as it moves from low-level image structure toward semantic features.

03 / REGULARIZATION
LRN → overlapping pooling → dropout

LRN follows Conv1 and Conv2; overlapping 3×3 pooling follows those normalized layers and Conv5; dropout is used in the first two fully connected layers.

04 / PAPER TO REPRODUCTION
Original: 2 GPUs · Reproduction: RTX 5050

The paper distributed the convolutional work across two GPUs. The reproduction runs locally on a single RTX 5050, which is one of the differences discussed later in the analysis.

04 / ABLATION STUDIES

Reproducing the paper's ablations.

The original AlexNet paper tested individual architectural choices rather than presenting only the final network. Two of those ablations were reproduced on a smaller four-layer CNN using CIFAR-10: ReLU vs Tanh, and LRN vs no LRN.

ReLU vs Tanh

The activation function is the variable being isolated. Both versions use the same four-layer CNN; only the nonlinearity changes.

LRN vs No LRN

Original paper

  • ReLU networks reached 25% training error substantially faster than equivalent Tanh networks.
  • The paper reports the ReLU comparison on a four-layer CIFAR-10 network with independently selected learning rates and no regularization.
  • For LRN, the paper reports a CIFAR-10 four-layer CNN test error of 13% without normalization and 11% with normalization.

Reproduction

  • ReLU/Tanh: a four-layer CIFAR-10 CNN trained with Adam, with early stopping applied at the recorded accuracy threshold.
  • LRN/no-LRN: the four-layer CIFAR-10 CNN was trained for 10 epochs with validation data.
  • The graphs above show the recorded error histories from the corresponding ablation experiments.

06 / REPRODUCTION GAP

The numbers didn't match. That's part of the experiment.

The original paper reported 37.5% Top-1 error and 17.0% Top-5 error on its test data. That corresponds to approximately 62.5% Top-1 and 83% Top-5 accuracy. The implementation did not reach those numbers on the available validation evaluation.

Original paper

  • ~62.5% Top-1 accuracy
  • ~83% Top-5 accuracy
  • Test-data evaluation
  • Multi-GPU setup

Reproduction

  • 52.86% validation Top-1 accuracy
  • 75.73% recorded validation Top-5 metric
  • Validation evaluation
  • Single RTX 5050

PCA color jitter

The implementation used the simpler transformations described in the paper but did not implement PCA color jittering.

Multi-GPU training

The original setup used multiple GPUs and cross-GPU connections; the implementation was trained on a single RTX 5050.

Learning-rate schedule

An earlier learning-rate reduction was identified as another possible contributor to the difference.

No labeled test set

The available test labels were not available, so evaluation was performed on the validation set. No hyperparameter tuning was performed.

09 / TAKEAWAY

A model is more than its architecture.

The implementation made the practical side of a classic deep-learning experiment visible: the dataset pipeline, preprocessing, compute, training schedule, evaluation choices and the small implementation details that can separate a reproduction from the original result.

AlexNet was published in 2012. Rebuilding it locally made me appreciate how much of deep learning is everything around the model itself.
